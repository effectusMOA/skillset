# Research Skill Set

연구 아이디어를 근거와 반박으로 구체화하고, 그 논리를 발표 자료로 전달하는 재사용 가능한 스킬 모음입니다.

## 스킬

| 이름 | 하는 일 | 결과 |
|---|---|---|
| [brainstorm](skills/brainstorm/SKILL.md) | 두 에이전트가 독립적으로 선행연구를 조사하고, 다른 분야의 해결 원리를 검토하며, 반박·수정으로 연구안을 구체화합니다. | 근거가 연결된 top-down 설명, 검증 가능한 실험안, 합의 또는 미해결 쟁점 |
| [research-ppt](skills/research-ppt/SKILL.md) | 선행연구의 성과·한계·본 연구 기여를 연결하고, 프레임워크·핵심 수식·예상 출력과 대본을 구성합니다. PPT 전문가 에이전트의 피드백을 받아 수정합니다. | 편집 가능한 연구 발표 PPTX, 요청 시 슬라이드별 대본·번역 |

## 사용

```text
$brainstorm
새로운 카메라 환경에서 자율주행 VLA가 실패하는 문제를 연구하고 싶습니다.
로봇 VLA의 폐루프 강화학습 선행연구를 바탕으로 두 에이전트가 논의해주세요.
기존 행동 생성부를 유지하고, 한 대의 로컬 서버에서 검증 가능한 아이디어를 원합니다.
```

독립 에이전트를 실행할 수 있는 호스트와 문헌 접근 도구를 사용합니다. 스킬 폴더 자체가 에이전트 실행 엔진은 아닙니다. 도구가 없으면 독립 논의를 가장하지 않고 필요한 조건을 알립니다.

### 연구 발표 PPT

```text
$research-ppt
첨부한 연구 제안 PPT를 수정해주세요. 선행연구는 1–3장으로 압축하고,
별도 종합 장에서 인사이트 → 한계 → 본 연구의 기여를 설명해주세요.
전체 프레임워크 뒤에는 운영 파트별 핵심 수식 하나씩만 설명하세요.
PPT 전문가 에이전트의 피드백을 받은 뒤 수정하고,
최종 PPT 표현에 맞춘 10분 영어 대본과 한국어 번역도 작성해주세요.
```

`research-ppt`는 실제 연구 발표를 수정하며 나온 요구사항을 정리한 스킬입니다. [요구사항 적용표](skills/research-ppt/references/requirements-map.md)에 선행연구 표, 제목, 프레임워크, 수식, 예상 결과, 번역, 대본과 전문가 검토 기준을 연결했습니다. 특정 연구의 이름·학번·데이터·슬라이드는 포함하지 않습니다.

PPT 전문가 검토에는 호스트가 허용하는 실제 독립 에이전트 기능이 필요합니다. 사용할 수 없으면 검토 미실행을 명시하며, 단일 에이전트의 자기 검토를 독립 검토로 보고하지 않습니다. PPT 제작·렌더링 도구는 현재 환경에서 사용할 수 있는 도구를 선택합니다.

## 진행 방식

1. 사용자의 목적·조건을 정리합니다.
2. A와 B가 서로의 초기안에 영향받지 않고 선행연구와 다른 분야의 해결책을 조사합니다.
3. 핵심 메커니즘과 근거가 있는 아이디어를 각각 제안합니다.
4. 모순, 논리적 비약, 기존 연구와의 중복을 지적하고 수정안을 주고받습니다.
5. 두 에이전트가 같은 최종안에 명시적으로 동의하면 합의합니다. 기본 여섯 번의 교환 안에 합의하지 못하면 미해결 쟁점과 판별 실험을 남깁니다.
6. 결론과 큰 그림부터 구현·실험 세부사항까지 top-down으로 설명합니다.

합의는 실험할 가치가 있는 가설에 대한 동의입니다. 효과 입증이나 논문 채택을 의미하지 않습니다. 실험 실행이나 외부 게시를 자동 허가하지 않습니다.

## 결과와 검증

작업 디렉터리의 `output/brainstorm/<주제>/`에 `report.md`와 `session.json`을 저장합니다. JSON에는 근거, 아이디어 변경, 반박, 최종안에 대한 독립 승인이 연결됩니다.

```bash
python3 skills/brainstorm/scripts/validate_session.py path/to/session.json
python3 -m unittest discover -s tests -v
```

검증기는 에이전트 식별자, 출처 참조, 남은 차단 쟁점, 최종안 변경 후 무효가 된 승인을 검사합니다. 논문 내용이나 실제 에이전트 실행 자체를 자동 증명하지는 않습니다.

PPTX는 읽기 전용 검사기로 실제 발표 순서와 텍스트, 관계 오류, 표·수식·그림 개수 및 시각 확인이 필요한 경고를 확인할 수 있습니다.

```bash
python3 skills/research-ppt/scripts/inspect_pptx.py path/to/final.pptx --expect-slides 14 --output output/pptx-audit.json
```

`14`는 예시 장수입니다. 검사기만으로 렌더링·수식 의미·논문 근거·편집 가능성이 검증되는 것은 아닙니다. 최종 파일 렌더와 PPT 전문가의 내용·구성 검토를 별도로 진행합니다.

PPT 검사기의 독립 테스트는 아래처럼 실행합니다. 검사기와 테스트는 Python 표준 라이브러리만 사용합니다.

```bash
python3 -m unittest discover -s tests -p test_inspect_pptx.py -v
```
